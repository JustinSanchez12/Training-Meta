# docs/

| File | Purpose |
|------|---------|
| `spec.md` | Spec for the feature currently being built. Written by the `planner` agent and overwritten per feature. |
| `ape-api.md` | APE platform reference (optional AI layer, server-side only). |
| `archive/` | Old tracking files (`tasks.md` from the vanilla-JS build). |

To keep an older spec, copy it to `docs/specs/<slug>.md` before starting the next feature.
